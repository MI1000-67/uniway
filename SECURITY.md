# Reporting a security problem

This prototype handles map images locally and does not provide server-enforced session revocation. We welcome reports about data retention, unsafe imports, camera lifetime and misleading route confirmation.

Do not put a private campus layout, personal information, credentials or exploit payload containing sensitive data in a public issue. Use GitHub's private vulnerability reporting if the repository has it enabled. If that option is absent, contact the maintainer through the GitHub profile to arrange a private channel; no dedicated security inbox or response SLA is configured yet.

Only the current main branch is maintained at this stage. We will document affected versions, the fix and any practical mitigation when a verified issue is resolved. Do not describe a public source release as a security audit.
