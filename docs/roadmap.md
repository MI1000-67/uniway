# Roadmap

## Next: prove the first slice

Run the Android/iPhone checklist. Compare OCR against a small permitted map set with known labels and paths. Measure cold-start time, peak memory and cancellation behaviour. Record errors as openly as successful examples.

## Then: real campus review

Define map ownership and permission, route direction, entrance nodes, geometry and reviewed evidence. Repair and verify the v2 survey workbook/exporter separately. Import its data only after it rejects missing or inconsistent records. Replace demo QR links with versioned, reviewed campus IDs before printing physical codes.

## Later: broader access

Add Tamil/Sinhala wording and OCR after local testing. Design cross-level stairs/lifts and access conditions. Evaluate offline loading and update behaviour without weakening expiry. Keep sustainable points evidence-backed; do not invent CO2 savings.

These are priorities, not delivery promises. Open a focused issue before beginning a larger feature.
