# Uniway contributor context

`C:/Project/experiment` is the main project. The approved UI uses `#058C42`, glass panels, and warm decorative lamps in the fictional demo. Core work must preserve those design tokens unless the user requests a design change.

The sibling `anti unieway/uniway-date-publish` provided algorithms; it is not the main app. Source-derived modules are in `src/engine/imported`. Keep their MIT notice. Never restore filename-based campus templates or connect rooms through walls.

Images, OCR and routing stay local. Keep worker/core/language URLs on this app's origin. No cloud inference, API keys, telemetry, or automatic upload persistence. Detection creates a draft; pedestrian access, entrances, scale, north and accessibility need review. Multiple uploads are independent maps, not automatically connected floors.

Write DX alongside core changes: document setup, public contracts, failure behavior and reproducible checks. Add synthetic regression fixtures; keep private uploaded maps out of source control. Do not invent accuracy benchmarks or model-training claims.

Use `npm run check`, focused tests, and `npm run build` for relevant code changes. Run `npm run engine:check` when OCR assets change. Browser workflows require a local preview and installed Edge or a configured Playwright browser. Update `VALIDATION.md` with actual results and limits. Local-only work does not imply deployment or GitHub publishing.
